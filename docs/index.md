# pyopia-gui

An open-source graphical interface for [PyOPIA](https://github.com/SINTEF/pyopia).

This documentation is being built up alongside the application itself.

- **[Installing pyopia-gui](installing.md)** - getting it downloaded (or built from
  source) and running.
- **[Using pyopia-gui](usage.md)** - the app itself once it's running, including
  setting up and configuring your own PyOPIA projects.
- **[Design decisions](decisions/INDEX.md)** - the reasoning behind pyopia-gui's
  architecture and technical choices.
