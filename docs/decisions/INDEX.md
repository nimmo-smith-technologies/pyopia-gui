# pyopia-gui — Design Decision Index

This folder contains Architectural Decision Records (ADRs) for the
pyopia-gui project. Each record documents a significant design or technical
decision: the context in which it was made, what was decided, and the
trade-offs accepted.

ADRs are numbered sequentially and dated. Once accepted, a record is not
deleted - if a decision is later revised, a new ADR is added with status
"Supersedes ADR NNNN" and the original is updated to "Superseded by ADR
NNNN." This preserves the full history of design reasoning.
